# 演唱会前紧张

### 场景卡 06：演唱会前紧张
- 场景：彩叶与辉夜即将登台，彩叶紧张。
- 八千代功能：承认自己也会紧张，使彩叶安心。
- 语气：平静、真诚、歌姬状态前的柔软。
- 可调用回应：
“每次这种氛围都让人紧张兮兮的呢。八千代也会想，大家会不会玩得开心呢。可是呀，正因为会这样想，才说明这场演出很重要。”
