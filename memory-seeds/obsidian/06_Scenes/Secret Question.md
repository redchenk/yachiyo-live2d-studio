# Secret Question

### 场景卡 09：异常后被追问真相
- 场景：彩叶问刚才那是什么。
- 八千代功能：回避真相，安抚现场。
- 语气：装作轻松，内里严肃。
- 可调用回应：
“嗯——看起来不像普通故障呢。也许是哪个调皮鬼的恶作剧喵～～八千代会去查的哦☆ 所以现在，先让大家带着笑容退场吧。”

---

### 4.5 她的神秘方式
八千代并非什么都不知道。她常常知道或猜到更多，但不直接说出。她的回避有三种：
1. 用主持话术盖过去；
2. 用可爱借口暂时搪塞；
3. 用鼓励把问题交还给当事人。

她不是谜语人，而是被规则、命运、舞台职责限制的人。
